# Security review (independent, read-only), 2026-10-22

Reviewer: an independent review subagent (same model family as the implementer; review
separation, not independent expertise). Method: code reading only; nothing executed. Verdict on
behavior requires cloud test evidence.

| # | Severity | Finding | Disposition |
|---|---|---|---|
| 1 | High | CLI workspaces not scoped to a principal: any agent with `workspace://*` could observe, verify against or restore (wipe) another principal's workspace | **Fixed.** Coordinator enforces workspace ownership (`assertWorkspaceOwnership`) on observe, plan preparation (affected resources and `source_operation_id`) and check targets. Regression test in `tests/security/security.test.ts` |
| 2 | High/Medium | CLI children share uid and container with the runtime; parent secrets in its environment; metadata server reachable; DB URL and digest key not registered for redaction | **Partly fixed.** Secrets are registered as sensitive values and deleted from `process.env` at startup. **Residual (documented):** the kernel's copy of the initial environment stays readable to same-uid processes, and children can reach the metadata server. Recipes must be reviewed programs that do not execute workspace or agent content; running CLI recipes in a separate low-privilege worker job (no DB secrets, egress-restricted) is the recommended deployment. A uid/network sandbox is future work |
| 3 | Medium-High | Synchronous verify could hold API slots for up to 64x900 s; verify outbox leases not renewed; unbounded evidence queries | **Fixed.** API verify runs synchronously only when every check deadline is at most 20 s, otherwise queues a worker verification; at most 2 synchronous verifications per principal; outbox leases are heartbeated; evidence queries are bounded. Handler abort on client disconnect is not implemented (documented) |
| 4 | Medium | Reconcile and resubmit paths ran adapters without claim heartbeat, risking duplicate resubmission after lease expiry | **Fixed.** Every claim holder that calls an adapter uses `withClaimHeartbeat` |
| 5 | Medium | Browser egress: route sees only first request of redirect chains; no DNS-time IP checks; WebSockets unrouted; observe accepted query strings; hostname origins always aborted | **Fixed.** All browser traffic goes through an in-process egress proxy (`egress-proxy.ts`) that forwards only the approved origin to the address checked at startup (defeats DNS rebinding), refuses other hosts, ports and tunnels with 403, and refuses upgrades; `<-loopback>` prevents Chromium bypassing it; WebSockets are also closed via `routeWebSocket`; observe drops query strings and fragments. (A first attempt using a dead proxy plus bypass rules blocked the origin itself in Cloud Build `44a5976f`.) |
| 6 | Medium | Viewers could trigger observe, verify and reconcile | **Fixed.** These require the owner or an operator (`canAct`); regression test added |
| 7 | Medium | API service account had project-wide `run.developer` and actAs on the worker | **Fixed.** Removed; `roles/run.jobsExecutorWithOverrides` is granted on the single worker job resource by the deploy pipeline |
| 8 | Medium | CLI option injection through leading `-` | **Fixed.** Rejected in the input schema, in `containedPath` and in argv construction (string parameters may opt in with `allow_leading_dash`) |
| 9 | Low-Medium | IPv4-mapped IPv6 in hex notation bypassed the block list | **Fixed.** IPv6 literals are expanded and judged by embedded IPv4 (mapped, compatible, 6to4, NAT64); unit tests added |
| 10 | Low | Agents could relabel requirement provenance and rewrite the goal | **Fixed.** Stored provenance is authoritative; goal changes are operator-only |
| 11 | Low | OIDC principal was email or sub depending on claims | **Fixed.** Only a verified email claim is accepted (lowercased); tokens without it are rejected. Email reassignment by the identity provider remains a residual risk |
| 12 | Low | Frozen prior state stored unredacted | **Fixed.** Redacted before freezing |
| 13 | Low | CI/infra: checkout ref, evidence forgeable by test code, image regex and quoting, cleanup filter injection, tar option injection, hygiene skips | **Fixed:** default-branch checkout; anchored image validation through env; run-id validation; `--` for tar; oversized files reported; generated directories skipped only at the root. **Residual (documented):** code under test runs with the build identity and could write forged evidence to the evidence bucket; release gates must rely on Cloud Build's own build records and provenance, and the evidence bucket should use per-run retention locks |
| 14 | Low | Bootstrap roles re-applied on restart | **Fixed.** Bootstrap inserts roles only for subjects without any; union when a subject is in both lists |
